Captured 2026-10-09 from the maintainer's Codev use and screenshot reports in this development conversation. Original report dates and exact installed build IDs were not consistently preserved, so this is a qualitative triage log. “Current source” means the merged Release 2 candidate source, not proof that the same behavior is present in an older installed release.

| Observed friction | Triage and current evidence | Status |
|---|---|---|

Core tests cover the compound deletion/Git command shape and destructive execution; the exact Deny regression verifies no command runs and no dialog appears. | Fixed in current source; recheck after Release 2 installation. |
| Codev repeatedly asked to enter or connect an OpenAI API key, and the user expected startup reconnection. | P2 saves newly entered keys to the OS vault before model discovery, even if discovery fails. Headless regressions cover the default and opt-out; P6 still requires manual provider/key restart QA. | Automated reconnect preference coverage added in this change; verify native credential-vault restart behavior in the Release 2 manual pass. |
