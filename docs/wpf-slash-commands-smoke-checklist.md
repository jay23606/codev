# WPF slash-command smoke checklist

- [ ] Type `/` in the composer. Confirm a small suggestion popup appears above the composer without reserving footer space, with only commands supported by WPF and the saved prompt templates.
- [ ] Use Up/Down and Enter to run a built-in command; use the mouse on a suggestion too. Confirm exact `/status` runs locally and displays the current status without an Ollama or hosted API request.
- [ ] Run `/clear`, decline the confirmation, and confirm history remains. Accept it and confirm messages and summary clear while the project, model, and file-change history remain. Confirm the command refuses while this conversation has active or queued requests.
- [ ] Run `/compact` on a conversation with enough complete turns. Confirm it uses the existing review/summary flow and leaves the original transcript available.
- [ ] Run `/plan` and `/code`; confirm their existing mode restrictions and OpenAI workspace-sharing consent still apply. Run `/model` and confirm it opens the model picker.
- [ ] Run `/export` and confirm the existing Markdown export flow opens. Run `/init` and a saved `/template-…`; confirm each inserts editable text and sends nothing until the user sends it.
- [ ] Run `/commands` and confirm it shows and opens `%LOCALAPPDATA%\Codev\commands`; with a trusted project attached, confirm it also shows and opens `<project>\.codev\commands`. Create same-named user and project `inspect.md` prompts, type `/`, and confirm the trusted project command appears as **PROJECT** and overrides the **USER** command. Choose it, fill its `name=` slots, press Enter, and confirm the expanded Markdown prompt is inserted for review rather than sent. Edit the file, rerun it and confirm the latest contents are used. Revoke trust while suggestions are open and verify a stale project command cannot execute; confirm the user command becomes available again. With an untrusted project, confirm the project path is unavailable and no project command is loaded. Delete the fixtures and confirm neither prompt executes scripts.
- [ ] Add malformed frontmatter, invalid UTF-8, an oversized command file, a symlink, an undeclared placeholder, and a command named after a built-in; verify each is skipped with a useful local status. Test missing, duplicate, unknown, unquoted-space, quoted-space, and unclosed-quote arguments; malformed invocations must remain editable and never reach a model.
- [ ] Type `@` and confirm file mention suggestions continue to work. Type an unsupported slash name and confirm it is treated as ordinary user text.
- [ ] Start a long response and queue two follow-ups. Verify each queued user message is labeled **QUEUED** and its context menu offers **Steer · run next**, **Edit queued prompt**, and **Remove from queue**. Steer one and confirm it runs next after the active response; edit the other and confirm the revised text is sent; remove a third and confirm it does not run. Turn **Queue off** for this conversation and verify new prompts are blocked while any request is active or queued; turn it back on, restart the app, and confirm the setting persists. Pause/resume the remaining queue and verify saved requests stay ordered after restart.
